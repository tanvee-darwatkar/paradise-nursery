# Paradise Nursery Shopping Application

An e-commerce React web application for browsing and purchasing house plants, built with React, Redux Toolkit, and CSS.

## Features
- Interactive landing page with background imagery and company overview.
- Plant listing page categorized by plant type (Air Purifying, Aromatic, Low Maintenance).
- Shopping Cart powered by Redux Toolkit state management.
- Dynamic total cart item counter in navigation header.
- Cart management including quantity adjustment, item removal, subtotal computation, and total cost display.

## Tech Stack
- React
- Redux Toolkit (`@reduxjs/toolkit` and `react-redux`)
- CSS3
